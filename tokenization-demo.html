Tokenization: How Models Break Text Apart

A model never reads letters or words. It reads numbers. Before anything else happens, text is chopped into pieces called tokens, and each token is looked up in a fixed vocabulary. This tool uses the real GPT‑2 tokenizer, running in your browser, so every split below is exactly what the model would actually see.
